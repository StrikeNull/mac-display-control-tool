# DisplayBar 推广文案

## 一句话

DisplayBar 是一个 macOS 状态栏多屏控制工具，支持屏幕开关、主屏设置、分辨率、刷新率、HiDPI、HDR 和 ColorSync 颜色配置。

## V2EX / 少数派标题

```text
分享一个 macOS 状态栏多屏控制工具：支持 HDR、刷新率、HiDPI 和颜色配置
```

## 中文发帖正文

```markdown
我写了一个 macOS 状态栏多屏控制工具 DisplayBar，主要解决外接屏用户经常要切换设置的问题。

它可以在状态栏里完成这些操作：

- 开启/关闭外接屏
- 设置主屏幕
- 切换分辨率和刷新率
- 开关 HiDPI
- 开关 HDR
- 尝试 10-bit 颜色位数
- 切换 ColorSync 颜色配置
- 快速切换扩展、复制、仅主屏、仅副屏
- 一键跳转到 macOS 显示器排列设置

项目是开源的，Release 里有 DMG，可以直接下载后拖到 Applications 使用。
目前没有签名和 notarize，首次打开需要在 macOS 隐私与安全性里允许。

GitHub:
https://github.com/StrikeNull/mac-display-control-tool

下载:
https://github.com/StrikeNull/mac-display-control-tool/releases/tag/v0.1.0

这个工具主要是为自己的多屏场景写的，如果你也经常折腾外接屏、HDR、HiDPI、刷新率和颜色配置，欢迎试试看。
```

## English Short Post

```markdown
I built DisplayBar, a small macOS menu bar utility for managing external displays.

It supports:

- enable/disable displays
- set the main display
- change resolution and refresh rate
- toggle HiDPI and HDR
- attempt 10-bit color depth
- switch ColorSync profiles
- quick display modes: extend, mirror, main-only, secondary-only
- open macOS Display Settings for arrangement

GitHub:
https://github.com/StrikeNull/mac-display-control-tool

Release:
https://github.com/StrikeNull/mac-display-control-tool/releases/tag/v0.1.0

The app is open source and currently unsigned/not notarized, so macOS may require manual approval on first launch.
```
